# Store Coach — Human-Friendly Redesign

**Scope:** Store Coach only. AI Command, Recommendations, Automation, GrowthIQ, and PatternAI were not touched.

## What changed

Store Coach no longer behaves like a robotic data reporter. The page is now a warm daily coaching check-in: a friendly compass avatar, plain-English briefings, priority cards that explain *why* they matter, simple weekly goals, motivational journey tracking, and coach-style options.

### Removed (duplicate / robotic)

- Robot (`Bot`) icon — replaced with a compass avatar and a presence dot
- Voice / speak / “Voice on higher plans” from the Store Coach page
- Full chat interface (“Ask your Coach”, composer, message limits)
- “Ask Coach” header button
- Board-like chat usage pills
- “Upgrade to Start/Growth/Commander” wording in locked notes

### Added / redesigned

- Warm header: time-based greeting, merchant name from the real shop domain, “Just getting started” engagement pill, streak, Morning Huddle + settings
- Today’s briefing with honest empty / generating / ready states and a single primary CTA
- Priority cards with category, time, impact, and a why-it-matters line
- Simpler weekly goals with friendly feasibility (“Well within reach”)
- “Your store’s best days” instead of a technical heatmap dump on the home page
- Journey / achievements with motivational streak copy (never a sad “0-day streak” headline)
- Coach style picker (Friendly / Professional / Motivational / Analytical)
- Value strip: daily tip, this week’s wins, and a quick lesson — all derived from real store state
- Cleaner plan card: what the merchant has + one Upgrade Plan CTA
- Warmer light theme (off-white canvas, visible card shadows, purple + orange coach accents)

## Zero fake data

Tips, celebrations, and best-day insights only render when the real huddle, priorities, heatmap, goals, or badges support them. Empty stores get honest empty states. No invented percentages or industry “studies.”

## Plan gating

Unchanged backend matrix. Upgrade CTAs always read **Upgrade Plan**.
